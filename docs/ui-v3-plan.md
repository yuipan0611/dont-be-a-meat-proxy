# UI 第三版實作邊界

目標：讓程式新手從全貌走到函式，讀懂每個零件的用途、輸入輸出及故障影響。基線 master 101363c，web 12/12、client mail 45/45 通過。

分段：研究現成 C4／目錄／畫布方案；自動掃描追蹤原始碼與部署設定產出 atlas；以既有唯讀 API 呈現五層與流程播放；執行 web/client 回歸及桌面手機 Playwright。

主要改動 web/scripts、web/public、架構測試、Docker 建置來源與交付文件。沿用固定靜態資產、session、Discord OAuth、每次查驗成員／固定 group、唯讀 code API；不修改 client、SQL schema、部署憑證。新增函式白名單由追蹤原始碼建置，排除秘密、測試與 spikes。風險為中：快照範圍擴大，須證明來源限制、登入／撤銷與無任意路徑讀取維持。

視覺方向：閱讀與操作混合；淺灰紙面、深墨綠文字、少量翡翠色指示選取；左側層級導覽、中央有邊界的架構畫布、右側零件說明。借用 C4 語意與 Dynamic 編號序列、React Flow 的選取／縮放／沿線移動互動；保留既有 SVG 與 CSP，不引入整套服務目錄後端。L2 為本專案增加的協議層。

證據限制：架構關係人工核對＋靜態擷取；流程動畫是教學示意，不是假裝即時流量。來源快照不能證明服務已上線。實際 Discord/VPS 及新手使用測試留給 PM/維護者。
